# Student Marks Analyzer

A C++ mini project that analyzes the marks of up to 100 students.

## Features
- Accepts student count between 1 and 100 (rejects invalid input)
- Reads and stores marks in an array
- Calculates total, average, highest and lowest marks
- Counts passed and failed students (pass mark = 50)
- Uses separate functions for each operation

## How to compile and run
g++ project.cpp -o project
./project        (Windows: project.exe)
